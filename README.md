## Conteúdo

- Exercícios_Python_MatheusLuiz_6ºB_Noturno.ipynb: lista de 50 exercícios de
Python cobrindo variáveis, estruturas de repetição, funções, listas,
dicionários, módulos e tratamento de exceções.

- Exercicios_DataScience_MatheusLuiz_6ºB_Noturno.ipynb: lista de 80 exercícios
de Data Science cobrindo NumPy (arrays e álgebra linear), SciPy (otimização,
integração, interpolação e transformadas de Fourier), Pandas (manipulação de
DataFrames) e Matplotlib (visualização de dados).

- vendas.xlsx: base de dados de apoio utilizada nos exercícios de Pandas.

- SVM_Regressao_MatheusLuiz_6ºB_Noturno.ipynb: atividade de previsão de preços
de imóveis com SVR usando o dataset Housing. Inclui análise dos dados,
tratamento de valores ausentes e outliers, padronização, comparação de
kernels e GridSearchCV. O modelo é avaliado com R², MAE, RMSE e gráfico de
valores reais e previstos.

- Modelos_IRIS_MatheusEJoao_6ºB_Noturno.ipynb: atividade com SVM, Árvore de
Decisão, Floresta Aleatória e XGBoost usando o dataset Iris. Os modelos são
executados com e sem GridSearchCV e comparados pela acurácia e sensibilidade.
Inclui matrizes de confusão e visualização das árvores.

- FishMorphDB_MatheusLuiz_6ºB_Noturno.ipynb: atividade de classificação das
famílias de peixes com SVM usando o dataset FishMorphDB. Inclui análise dos
dados, distribuição das famílias, divisão de treino e teste, padronização,
validação cruzada, GridSearchCV, acurácia e matriz de confusão. O gráfico da
matriz apresenta um recorte das 10 famílias mais frequentes no treino.

## Observações

As atividades foram desenvolvidas no Google Colab e no Kaggle.
Os notebooks de Housing e Iris usam caminhos do Kaggle. Para executá-los em
outro ambiente, ajuste o caminho do CSV. No notebook FishMorphDB, envie o
arquivo FISHMORPH_Family_Dataset.csv para os arquivos do Colab.
